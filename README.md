# ThermoSurvey · 建筑保温热像点检

ThermoSurvey 根据建筑墙面的热线性灰度数据量算表面温度、检查相对低温区并保留现场复查证据。练习墙面和现场图均为合成素材。

运行 `./start.sh`，打开 [本地工作台](http://127.0.0.1:19888/)。通过 `THERMOSURVEY_PORT` 改端口。`./start.sh stop` 移除服务容器，保留命名数据卷。

- 导入未经调色的 16 位单通道 PNG、TIFF，或载入合成练习。支持 16 MB、200 万像素以内。码值 0 和 65535 视为缺测。
- 温度用码值乘每码温差再加零码温度计算。默认给厘开尔文编码使用，相机使用其他线性编码时先按已知标定修改。显色范围与调色板只控制显示。
- 使用热图上两点设置检查区、参考区或温度剖线。长度和面积采用当前统一的毫米像素标尺，适用于近似正对且比例一致的墙面。
- 区域温度显示有效像素、中位温度和有效面积。温度分布额外保留两侧溢出温区，缺测像素单列。
- 低温区的门槛是参考区的有效温度中位数减设定温差。低温像素按四邻接归区，列表保留面积最大的 80 区，点行可在源图定位。
- 温度剖线在两端之间等距采样、取最近原图像素，支持沿曲线和表格回看位置。缺测温度留空。
- 现场可见光底图可单独上传，也可通过「准备现场照片」处理并附到当前热图。它供并排辨认现场，温度来自原始热图。
- 可保留画框和标定，或保存当前检查。重开检查仍使用当时的设置、关联底图与读数，可下载 CSV、带标记热图和 16 位源图。

导入只接收线性码值热图。相机私有辐射格式、发射率估计、倾斜墙面和多个距离的投影换算需要在工作台外处理。

容器采用锁定的 Python 3.12 依赖，也支持已验证的 Python 3.11 依赖。后台源码复算可运行 `python3 scripts/count_backend.py --project-root . --source-root thermosurvey --source-root image_lab --output backend-count.json`。
